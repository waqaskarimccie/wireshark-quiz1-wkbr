# Wireshark Quiz by Waqas Karim

An interactive Wireshark practice quiz in a single file. Open `index.html` in a browser.
Nothing is uploaded or stored: the questions, the mock Wireshark and the scoring all run in the browser.

## Publish with GitHub Pages
1. Create a public repository and upload `index.html` and this README.
2. Settings > Pages > Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
3. Open `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`.
